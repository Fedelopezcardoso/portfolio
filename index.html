Consejos de privacidad para vos

API usada

Se hace un fetch() a ipapi.co/json — una API pública, gratuita y sin clave. Devuelve en ~100ms: IP, ASN, ISP, ciudad, país, coordenadas del nodo y zona horaria.

fetch('https://ipapi.co/json/')
  .then(r => r.json())
  .then(d => console.log(d.ip, d.asn, d.org))

Datos del navegador

El navegador expone datos sin ningún permiso especial a través de la API de JavaScript:

navigator.userAgent   // browser + OS
navigator.language    // idioma
navigator.doNotTrack  // preferencia DNT
screen.width/height   // resolución
Intl.DateTimeFormat() // zona horaria local

Lo que NO se puede obtener

  • ❌ Nombre real o identidad
  • ❌ Dirección física exacta
  • ❌ Historial de navegación
  • ❌ Contraseñas o datos del sistema
  • ❌ IP privada (LAN) sin permiso
  • ✅ Sólo lo que el ISP hace público

¿Qué es el fingerprinting?

La combinación de resolución, idioma, navegador, zona horaria y más puede crear un perfil único sin cookies. Hasta el 87% de los usuarios son identificables sólo con estos datos.
